## <img src="https://raw.githubusercontent.com/AnalistaOtgan/AnalistaOtgan/main/assets/icons/cycle.svg" width="20" height="20"/> Como Funcionam as Atualizações Automáticas

O Axis utiliza o motor moderno **Velopack** para gerenciar o ciclo de vida do software:

1. **Checagem Silenciosa:** A cada inicialização, o Axis consulta este repositório via API de Releases do GitHub.
2. **Download Diferencial (Delta):** Em vez de baixar o instalador completo (~90 MB), o sistema baixa apenas os pacotes .delta.nupkg contendo as diferenças (geralmente poucos megabytes).
3. **Aplicação Atômica:** O update é baixado em segundo plano sem travar o operador de caixa e aplicado automaticamente na reinicialização do sistema.

## <img src="https://raw.githubusercontent.com/AnalistaOtgan/AnalistaOtgan/main/assets/icons/building.svg" width="20" height="20"/> Requisitos de Sistema

* **Sistema Operacional:** Windows 10 (Build 19041+) ou Windows 11 (64-bit)
* **Arquitetura:** x64
* **Conectividade:** Conexão com a internet para emissão SEFAZ e checagem de atualizações (com suporte a contingência offline)
* **Hardware Mínimo:** 4 GB RAM, 500 MB de espaço em disco livre
